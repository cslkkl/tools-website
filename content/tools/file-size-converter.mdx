## Frequently Asked Questions

### Is a kilobyte 1000 or 1024 bytes?
Technically, a kibibyte (KiB) is 1024 bytes and a kilobyte (KB) is 1000 bytes. However, in common usage and in this tool, we use 1024-based binary conversion (the convention used by operating systems like Windows).

### What's the largest unit?
A petabyte (PB) is 1024 terabytes (TB) — a scale used by data centers and cloud providers.
