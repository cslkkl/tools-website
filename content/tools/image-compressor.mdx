## What is an Image Compressor?

An image compressor reduces the file size of images while preserving visual quality. This is essential for website performance, email attachments, and saving storage space. Large images slow down websites and consume bandwidth — a compressed image can be 50-80% smaller with minimal quality loss.

Our image compressor uses the browser's Canvas API to compress images locally. Your images never leave your device.

## Why Use Our Image Compressor?

- **Adjustable quality** — Fine-tune compression from 10% to 100%
- **Image scaling** — Reduce dimensions to 75%, 50%, or 25% of the original
- **Side-by-side preview** — Compare original and compressed images before downloading
- **100% private** — Images are processed entirely in your browser. Never uploaded to any server.

## How to Use This Image Compressor

## Frequently Asked Questions

### Is my image uploaded to a server?
No. All processing happens using the HTML5 Canvas API in your browser. Your images never leave your device.

### What image formats are supported?
The tool accepts all common image formats: JPEG, PNG, WebP, BMP, and GIF. The compressed output is saved in the same format as the original.

### Will compression reduce image quality?
Some quality loss is inevitable with lossy compression, but you can control the trade-off with the quality slider. At 80-90% quality, the difference is barely noticeable.

### Is there a limit on image size?
The tool works best with images under 20MB. Very large images may take longer to process but will still work.
